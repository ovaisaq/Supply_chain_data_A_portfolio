# Supply Chain Analysis

A data analysis project for a global e-commerce company to analyze delivery operations, identify bottlenecks, and build a predictive system to reduce delays and improve profitability.

## Project Overview

This project analyzes delivery operations for a global e-commerce company operating across multiple regions. The company manages end-to-end order fulfilment including shipping and delivery for products like sporting goods.

## Business Problem

The company is facing inconsistent delivery performance where actual shipping times often deviate from scheduled timelines, leading to late deliveries and unpredictable order profitability.

## Features

- Exploratory Data Analysis (EDA)
- Delay analysis and visualization
- Profitability analysis
- Bottleneck detection
- Root cause analysis
- Time-based analysis
- Predictive modeling for late delivery risk

## Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Getting Started

1. Clone the repository
2. Install required packages: `pip install pandas numpy matplotlib seaborn scikit-learn`
3. Open the Jupyter notebook: `jupyter notebook supply_chain_p1.ipynb`
